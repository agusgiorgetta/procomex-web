# ProComex Web

Landing page institucional de **ProComex**, estudio de despacho aduanero y asesoramiento contable para importadores en Buenos Aires, Argentina.

## Sobre el proyecto

Sitio de una sola página pensado para captar consultas de empresas y particulares que necesitan:
- Despacho aduanero (importación/exportación)
- Asesoramiento contable e impositivo
- Gestión de ARCA
- Consultoría para nuevos importadores

Incluye secciones de servicios, equipo profesional (con página propia por cada integrante), preguntas frecuentes y formulario de contacto.

## Tecnologías

- HTML5 / CSS3 / JavaScript (vanilla)
- Formulario de contacto vía Netlify Forms
- SEO on-page: meta tags, Open Graph, datos estructurados (schema.org), sitemap.xml y robots.txt

## Estructura

- `index.html` — página principal
- `andrea-bevacqua.html`, `benjamin-badaro.html` — perfiles del equipo
- `terminos.html`, `privacidad.html` — legales
- `style.css` — estilos
- `assets/` — imágenes, íconos y scripts
